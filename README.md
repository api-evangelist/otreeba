Open Cannabis Data for Your Technology. Otreeba comes from the word "abierto" which means "open." Otreeba offers standardized cannabis data and normalization for cannabis seed companies, strains, brands, products, batches, retailers, and studies through a REST API.

**Areas:** Cannabis · Hemp · Clothing

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Otreeba: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
